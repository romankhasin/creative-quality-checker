КАК ЗАГРУЗИТЬ ПРОЕКТ

1. Распакуйте архив.
2. Откройте репозиторий:
   https://github.com/romankhasin/creative-quality-checker
3. Нажмите Add file → Upload files.
4. Перетащите в окно содержимое распакованной папки.
5. Внизу нажмите Commit changes.
6. Откройте https://vercel.com/new и импортируйте репозиторий.
7. После импорта откройте Settings → Environment Variables.
8. Добавьте OPENAI_API_KEY и отметьте Production и Preview.
9. Нажмите Deploy.

Vercel покажет новый адрес сайта после успешного развёртывания.

Не вставляйте API-ключ в GitHub. Скрытые файлы для загрузки не нужны.
