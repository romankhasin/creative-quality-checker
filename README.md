# Creative Quality Checker

Браузерный инструмент для пакетной технической проверки рекламных баннеров.

## Возможности

- точная проверка фактических размеров по справочнику форматов;
- приоритет эталона размера из имени файла, например `banner_300x250.png`;
- эвристическая проверка сетки, полей и близости элементов к краям;
- OCR дисклеймера в нижней части баннера на русском и английском;
- сравнение дисклеймеров внутри загруженной пачки;
- выгрузка результатов в CSV.

Изображения обрабатываются локально в браузере и не загружаются на сервер. При первом распознавании Tesseract.js загружает языковую модель.

## Запуск

```bash
npm install
npm run dev
```

## Проверка

```bash
npm run lint
npm run build
```
